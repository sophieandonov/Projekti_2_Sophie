# Elokuvahaku (TMDB AJAX App)

Natiivilla JavaScriptillä toteutettu verkkosovellus, joka hakee reaaliaikaista elokuvadataa The Movie Database (TMDB) -rajapinnasta.

## Ominaisuudet
- Suosituimpien, parhaiten arvioitujen ja tulevien elokuvien selaus pudotusvalikosta.
- Vapaa sanahaku TMDB:n elokuvatietokannasta.
- Toteutettu ilman ulkoisia JS-kirjastoja (Fetch API & dynaaminen DOM-manipulaatio).
Tunnetut virheet / puutteet
Ei sivutusta, ei elokuvan lisätietonäkymää, ei tyhjennys- tai nollaustoimintoa haulle.

Missä onnistuin? Sain haun toimimaan rajapinnasta ja tehtyä siistin korttinäkymän omalla JS- ja CSS-koodilla.
Mikä oli haastavaa? Oikean datan poimiminen ja virhetilanteet.
Mitä parantaisin, jos aikaa olisi enemmän? Lisäisin sivutuksen ja lisätiedot elokuville sekä tekisin DOM-päivityksestä turvallisemman.
Mitä opin HTML:stä, CSS:stä, JavaScriptistä ja DOM-skriptauksesta? Opin rakenteen HTML:llä, asettelun CSS:llä, datan haun fetchillä ja DOMin muokkaamisen JavaScriptillä.
Mikä jäi epäselväksi tai mistä haluaisin oppia lisää? Virheiden käsittelystä, tietoturvasta ja tarkemmista hauista.
